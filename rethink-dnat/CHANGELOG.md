# Changelog

## 0.1.50

### Added

- LG ThinQ 앱에서 설정한 장치 이름을 동기화해 관리 화면의 연결 장치 목록에 표시합니다.
- ThinQ 이름을 가져올 수 없거나 브리지에 로그인하지 않은 경우 기존 장치 목록과 로컬 제어는 그대로 유지됩니다.

## 0.1.49

### Fixed

- 기존 MQTT 엔티티에 워시타워 Configuration 분류가 적용되도록 설정 제어 5개를 같은 고유 ID로 안전하게 재등록합니다.

## 0.1.48

### Fixed

- 한국형 워시타워의 `36 e6` 명령 직후 상태와 `0xde` 이전/현재 상태쌍을 매핑해 전원 상태가 즉시 갱신되도록 했습니다.
- 한국형에서 7바이트 뒤로 이동한 건조기 상태 구간을 보정했습니다.
- 세탁기·건조기 전원을 실제 상태 피드백을 사용하는 토글로 변경하고, 나머지 설정 제어를 Configuration 구역으로 분리했습니다.

## 0.1.47

### Added

- `WTL_KPK_BDH_KR_01` 한국형 워시타워를 북미형 `WTL_FXU_BDV_NA_01` 기반의 전용 파서로 분리했습니다.
- 실제 장치 캡처에서 확인한 `0x78`/`0xeb` 102바이트 전체 상태 응답을 해석해 세탁기와 건조기 상태를 갱신합니다.

## 0.1.46

### Fixed

- H01에서 제거한 스팀 상태와 원격 스팀 제어가 기존 MQTT Discovery에 남지 않도록 명시적인 구성요소 제거 업데이트를 추가했습니다.

## 0.1.45

### Changed

- H01 식기세척기를 검증된 H11 device-type-204 자료에 맞춰 처음부터 다시 매핑했습니다.
- `32ec`의 태그 블록을 순서대로 해석해 마지막 `00 18` 블록을 현재 상태로 사용하고 `05 0d` 통계 블록은 제외합니다.
- ON/OFF 패킷이 모두 검증되지 않은 스팀 상태와 원격 스팀 제어 엔티티를 제거했습니다.

## 0.1.44

### Fixed

- H01 스팀 매핑을 최신 DNAT 런타임 소스 위에 다시 적용해 0.1.43의 장치 재접속 회귀를 수정했습니다.

## 0.1.43

### Added

- H01 식기세척기의 스팀 상태를 `data[12]`의 `0x80` 비트로 매핑했습니다.
- 원격 시작 명령의 옵션 `0x80`을 제어하는 스팀 스위치를 추가했습니다.

## 0.1.42

### Added

- 기기 모니터의 현재 메시지 이력, 분류 카운터, 순번을 한 번에 초기화하는 `이력 지우기` 버튼을 추가했습니다.
- 화면 이력 초기화는 진행 중인 캡처와 저장된 캡처 파일에 영향을 주지 않습니다.

## 0.1.41

### Added

- 캡처 파일명에 생성 일시와 첫 번째 메모를 포함합니다.
- 저장된 캡처 파일을 관리 화면에서 확인 후 삭제할 수 있습니다.

## 0.1.40

### Added

- 모든 ThinQ1/ThinQ2 장치의 원본 패킷을 모델 디코더보다 먼저 보존하여 미지원 패킷도 빠짐없이 표시하고 캡처합니다.
- 기기 모니터 메시지를 전체, 매핑됨, 미매핑 보기로 분류하고 각 개수를 표시합니다.
- 캡처 JSONL에 패킷별 `mapped` 판정값을 저장합니다.

## 0.1.39

### Added

- 기기 모니터 화면에서 RX/TX 패킷과 사용자 메모를 JSONL로 캡처할 수 있습니다.
- 캡처 파일을 앱 데이터 영역에 영구 저장하고 관리 화면에서 다시 내려받을 수 있습니다.

## 0.1.38

### Added

- H01 식기세척기의 상태, 코스, 시간, 문, 옵션, 전력 및 진단 패킷을 Home Assistant 엔티티로 매핑했습니다.
- H11 device-type-204 분석을 기반으로 전원, 일시정지, 재개, 취소, 설정 변경 및 가상 원격 시작 제어를 추가했습니다.

## 0.1.37

### Fixed

- 0.1.36의 기기 매핑을 최신 DNAT 런타임 소스 위에 다시 적용했습니다.

## 0.1.36

### Added

- `WTL_KPK_BDH_KR_01` 워시타워를 기존 WashTower 프로토콜 처리기에 매핑했습니다.
- `H01` 식기세척기에 읽기 전용 진단 상태 매핑을 추가했습니다.

## 0.1.35

### Changed

- 기존 Rethink 애드온과 안전하게 병행 설치할 수 있도록 애드온 식별자를 `rethink_dnat`으로 분리했습니다.
- Home Assistant 표시 이름을 `Rethink DNAT`으로 변경했습니다.

## 0.1.34

### Added

- LG 공식 DNS 응답을 유지하는 DNAT 모드를 추가했습니다.
- HTTPS 및 MQTT 연결에 SNI별 서버 인증서를 동적으로 발급합니다.

### Security

- ThinQ 2 bridge 활성화 시 기존 LG 계정의 기기를 삭제하거나 `initDevice=true`로 재등록하지 않습니다.
- 검증되지 않은 파괴적 등록을 막기 위해 ThinQ 1 bridge 활성화를 차단합니다.

## 0.1.1

### Added

- Home Assistant 애드온 저장소 및 애드온 패키지 구조를 추가했습니다.
- Supervisor MQTT 서비스 자동 검색을 추가했습니다.
- MQTT 서버 URL, 사용자 ID, 비밀번호 수동 설정 옵션을 추가했습니다.
- MQTT 자동 검색 실패 시 수동 설정으로 전환하는 폴백을 추가했습니다.
- Home Assistant ingress 관리 화면을 추가했습니다.
- 영어 및 한국어 애드온 설정 설명을 추가했습니다.
- 브라우저 언어를 감지하는 한국어 관리 UI 번역을 추가했습니다. 애드온 이름 `Rethink`은 번역하지 않습니다.
- 인증서, 브리지 상태 및 생성된 런타임 설정을 `/data`에 영구 보관하도록 구성했습니다.

### Changed

- 관리 화면의 홈 링크가 ingress 하위 경로에서도 동작하도록 수정했습니다.
- 루트 README를 Home Assistant 애드온 설치와 MQTT 설정 중심으로 개편했습니다.
- GHCR 패키지 공개 여부에 의존하지 않고 공개 GitHub `master` 소스를 직접 빌드하도록 애드온 Dockerfile을 변경했습니다.
- 설치 중 변경될 수 있는 `dev` 대신 릴리스된 `master` 브랜치를 기본 빌드 소스로 고정했습니다.
- Windows 또는 ZIP 기반 설치에서도 `/run.sh`가 실행되도록 LF 줄바꿈을 강제하고 빌드 중 CRLF를 정규화합니다.
- 신규 설치의 기본 Rethink 호스트 이름을 `rethink.lan`에서 `rethink.home.arpa`로 변경했습니다.

### Security

- MQTT 비밀번호를 로그에 출력하지 않습니다.
- 생성된 런타임 설정 파일 권한을 `0600`으로 제한합니다.
