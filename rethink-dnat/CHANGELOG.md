# Changelog

## 0.1.93

- Match the local `airclean` and `sleeptimer` component names so PAT-Cloud no longer keeps duplicate air-clean and sleep-timer entities.

## 0.1.92

- 실제 로컬 패킷 컴포넌트가 있는 값은 해당 로컬 엔티티만 사용하고 중복 PAT-Cloud 센서를 정리합니다.
- 로컬에 없는 상세 상태, 예약 정보 및 오늘 전력 사용량은 PAT-Cloud 센서로 유지합니다.
- 작은 화면에서 매핑 메시지 영역이 높이 0으로 줄어들지 않도록 반응형 스크롤 레이아웃을 적용합니다.

## 0.1.91

- 공식 ThinQ Connect PAT 상태와 지원되는 일일 에너지 값을 기존 로컬 MQTT 기기 아래의 읽기 전용 센서로 추가합니다.
- 모든 클라우드 센서 이름에 `(PAT-Cloud)`를 붙여 로컬 패킷 기반 센서와 구분합니다.
- 워시타워의 PAT 값은 기존 세탁기와 건조기 MQTT 기기에 각각 나누어 배치합니다.
- Rethink 전체 브리지, 개별 로컬 기기 또는 PAT 조회가 오프라인이면 관련 PAT-Cloud 센서를 `사용 불가`로 전환합니다.
- 애드온 재시작 직후에는 이전 PAT 값을 정상으로 재사용하지 않고, 새 조회가 성공한 뒤에만 센서를 온라인으로 전환합니다.
- 기기별 관리 모니터에 최신 PAT 상태, 에너지 프로필, 오늘 사용량 및 조회 오류를 별도 영역으로 표시합니다.
- 냉장고의 기존 로컬 문 열림 횟수·시간은 그대로 유지하며, 공개 PAT 프로필에 없는 냉장실·냉동실별 문 열림 횟수는 생성하지 않습니다.

## 0.1.90

- 냉장고 필터 엔티티 이름을 `청정 탈취 필터 상태`로 정리합니다.
- 공식 ThinQ Connect PAT의 읽기 전용 에너지 이력 API로 `오늘 전력 사용량` 센서를 추가합니다.
- 로컬 PAC 도어 이벤트로 `오늘 문 열림 횟수`와 `오늘 문 열림 시간`을 누적하고 애드온 재시작 뒤에도 보존합니다.
- 공개 API나 확인된 PAC 값이 없는 1일 물·얼음 사용량은 잘못된 센서를 만들지 않습니다.

## 0.1.89

- 잘못 생성된 냉장고 현재 선택 출수 종류 엔티티의 MQTT discovery를 명시적으로 정리합니다.

## 0.1.88

- 기존 출수 모드 선택 엔티티는 기본 복귀 모드 설정으로 유지합니다.

## 0.1.1

### Added

- Home Assistant 애드온 저장소 및 애드온 패키지 구조를 추가했습니다.
- Supervisor MQTT 서비스 자동 검색을 추가했습니다.
- MQTT 서버 URL, 사용자 ID, 비밀번호 수동 설정 옵션을 추가했습니다.
- MQTT 자동 검색 실패 시 수동 설정으로 전환하는 폴백을 추가했습니다.
- Home Assistant ingress 관리 화면을 추가했습니다.
- 영어 및 한국어 애드온 설정 설명을 추가했습니다.
- 브라우저 언어를 감지하는 한국어 관리 UI 번역을 추가했습니다. 애드온 이름 `Rethink`은 번역하지 않습니다.
- 인증서, 브리지 상태 및 생성된 런타임 설정을 `/data`에 영구 보관하도록 구성했습니다.

### Changed

- 관리 화면의 홈 링크가 ingress 하위 경로에서도 동작하도록 수정했습니다.
- 루트 README를 Home Assistant 애드온 설치와 MQTT 설정 중심으로 개편했습니다.
- GHCR 패키지 공개 여부에 의존하지 않고 공개 GitHub `master` 소스를 직접 빌드하도록 애드온 Dockerfile을 변경했습니다.
- 설치 중 변경될 수 있는 `dev` 대신 릴리스된 `master` 브랜치를 기본 빌드 소스로 고정했습니다.
- Windows 또는 ZIP 기반 설치에서도 `/run.sh`가 실행되도록 LF 줄바꿈을 강제하고 빌드 중 CRLF를 정규화합니다.
- 신규 설치의 기본 Rethink 호스트 이름을 `rethink.lan`에서 `rethink.home.arpa`로 변경했습니다.

### Security

- MQTT 비밀번호를 로그에 출력하지 않습니다.
- 생성된 런타임 설정 파일 권한을 `0600`으로 제한합니다.
